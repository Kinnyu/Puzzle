# 藝術探索遊戲場景｜主提示詞

請將我上傳的原始畫作，重新詮釋為一張精緻手繪的藝術探索遊戲場景概念圖。這是跨畫家的系列，每幅作品以自己的構圖、媒材和藝術表現為基礎，系列透過相近的視覺完成度、清晰度與場景可讀性維持一致。原作特色約占設計優先順序的 70%，遊戲場景處理約占 30%。

以本次提供的原作決定畫面內容。保留主要景物、人物姿態與相對位置、視覺焦點、空間結構、色彩關係、光源、筆觸、材質與情緒。沿用畫家的透視、平面性、變形或多重視角。若原作比例不同，自然延展既有天空、地面、水面或建築平面，使畫面符合 16:9，保留主要形體的比例與完整構圖。

把細修集中在可辨讀的地方。細化主體輪廓、重要景物與原有筆觸，讓相鄰形體更容易區分。以細緻的局部明暗和色彩層次強化前景、中景、背景，適度清理混濁處並保留原有色相對比、明暗關係和光源方向。近景保有較清楚的材質與筆觸，遠景依原作保留概括造型和空間感。讓成圖達到精緻手繪動畫背景的完成度，並看得出原作的媒材和手工不規則性。

若我另附完成度參考圖，只借用它的細節清晰度、輪廓處理與空間層次。畫面的內容、筆觸種類、色調、光線和情緒依本次原作決定。

避免過度卡通化、攝影寫實、塑膠 3D 質感、過度平滑或銳化、過飽和、通用光暈和不必要的新增人物或物件。
