# 星夜村落 · Unity 场景

打开 `Assets/Scenes/StarryNight.unity`。地形、住宅、教堂与植栽都保存在场景内。展开层级后可单独选择、移动、复制房屋或树木。网格与材质保存在 `Assets/StarryNight/Scenery`。房屋和树木的碰撞体随物件移动，编辑摆位后直接保存场景即可。

## 开场与行走

相机的编辑位置决定开场远景。`Approach guide` 标记控制进镇的镜头弧线，`Player at village entrance` 的位置与朝向决定落点。播放后远景保持静止，点击游戏画面开始推进。到达镇口后，WASD 行走、滑鼠环视、Shift 快走，Esc 释放滑鼠。镜头推进期间使用固定视角宽度，由相机与村落之间的实际距离形成近大远小的变化。地形与场景中的碰撞体共同约束玩家移动。

## 视觉验收

- 展开 `Landscape` 可分别选取远山与前方的蓝色山坡。在开场机位对照原画，山线从左侧低地经过中央山头，再向画面右侧抬升。进镇时，两层山坡应与近处的橄榄树产生视差。
- 展开 `Vegetation` 可找到山脚、田界和村内庭园的树群，每棵树都可单独移动。当前场景有 821 棵阔叶树、10 棵柏树及 112 栋住宅，另有教堂。`Buildings` 保存房屋和碰撞体，`Landscape/Village lanes` 的可见路面与地面碰撞使用同一网格。入口主街约宽 2.1 米，镇内两侧纵巷约宽 1.6 米。已在 Unity 播放模式验证远景停驻、点击推进、镇口交接及向前行走约 6.6 米，并沿主街和横巷检查玩家宽度的通行空间。
- 项目根目录的 `StarryNight-village-comparison.png` 并列展示原画、上一版及当前场景。两次 Unity 截图使用同一机位与 1280 × 720 画幅。取画面横向 35% 至 95%、底部 30% 作固定比较区域，通过物件遮挡后的可见像素测量，路面占比从 14.5% 降至 2.3%。在村内同一中景范围，树冠与屋顶投影宽度的中位数分别为 33.5 和 44.0 像素。

- 以 16:9 的 Game 视图对照《星夜》原画。东南山坡的开场机位应把 `Overlook cypress` 的树尖放在画面左侧约 21%、顶部下方约 6% 处；中央留给星涡，月亮在右上，教堂在下方村落中。前景柏树与右侧山脊均是可单独选取的立体网格。进镇时应能看到近树掠过，天空随视线转动。
- 在编辑模式打开场景，选中一栋房屋并移动；其门窗、屋顶与碰撞体应一起移动。重新打开已保存的场景后，物件应保有编辑的位置。
- 在远景按 W 应保持原位；点击后经过山坡，抵达入口才接受行走输入。
- 在街内检查窗格、门框、屋脊、墙角及路缘的深色描线。轮廓随物件转动，远处的细窗仍须可辨。实体表面的短笔以天空为基准，远处每笔覆盖的表面积增加。村落和山坡材质共用 `OilPigment.hlsl` 的 `SurfacePaint`，在笔触短轴上增加宽度，保留各表面的走笔方向。街道沿连续的纵巷或横巷坐标铺色，避免同一段路的笔触沿三角形接缝突变。
- 项目根目录的 `StarryNight-brush-sky-comparison.png` 取自一张 1920 × 1080 的街景。固定相机，分别裁切天空、近中远三处屋顶及三处路面，各取 72 × 30 像素并以相同倍率显示。色框中心距相机约 3.8 至 23.8 米。图中另附同机位窗框的修改前后对照。
