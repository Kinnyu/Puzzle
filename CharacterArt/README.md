## 選圖和嘴型

- 每個面向的 `_Idle` 是閉嘴站姿，`_Talk` 是微張嘴畫格。播放對話時，在**當前面向**的這兩張之間交替。停止說話時回到該面向的 `_Idle`。
- 梵谷的 `Front45` 和 `Side` 畫的是朝畫面右方的版本。向左時可用 `SpriteRenderer.flipX`，閉嘴和開嘴一起翻轉。背面保持閉嘴站姿。提奧、農婦和礦工目前使用朝向鏡頭的版本。
- 39 張透明 PNG 皆為 512 × 1024。Unity 以單張 Sprite 匯入，使用 550 PPU 和腳底附近的共用定位點。每組嘴型的畫布、透明輪廓和定位點相同。
- 每張畫格保留為獨立 PNG，方便單獨替換。若日後確定哪些角色會一起出場，再按同時使用的素材規劃 Sprite Atlas，Unity 可從獨立 PNG 打包。

## 留作參考的圖

- `CharacterArt` 是先前的工作圖，只有 `Assets/Art/Characters` 的版本供 Unity 選用。原本成熟梵谷的雙人概念畫格，以新的多面向版本和各面向嘴型接替。
- 手拿畫板、畫筆或信封的概念圖、帶場景或色暈的整張預覽、年齡與面向拼版、照片和嘴型參考板都留作美術參考。提奧的空手正面閉嘴與開嘴則有納入正式素材。

## 第四章路人

四款造型位於 `Assets/Art/Characters/Passersby`，可以重複配置給不同的路人。沿街移動時使用 `Side` 的單張站姿，朝左時使用 `flipX`。若要加上下晃動，可只移動顯示 Sprite 的子物件。開始交談時切到 `Front45`，沿用同面向的閉嘴和開嘴畫格。

## 遠近顯示與後續需求

角色圖已開啟 mipmaps 與三線性過濾，同一張圖在遠處會使用較低的紋理解析度。這是角色目前的遠距處理。若進場後仍需要更清楚的遠景輪廓，可按螢幕上的角色高度切到簡化圖，臨界範圍加上緩衝，避免來回切換。遠景可先共用閉嘴畫格。

梵谷目前有四個站姿視角。若轉身需要更細的八方向切換，再補斜後方；若角色需要實際走路，再補走路循環。提奧、農婦和礦工若要轉身，才需要對應面向。角色擺放、朝向選擇與對話觸發由各章場景設定接入。
